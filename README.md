# kakeibo

個人用の家計簿アプリ。ビルド不要の単一HTMLで、GitHub Pages から配信している。

**https://tmgr490.github.io/kakeibo/**

ホーム画面に追加すると、アプリのように起動してオフラインでも使える。

## 画面の構成

| 画面 | 中身 |
|---|---|
| **ホーム** | 今月（収支・次の引き落とし・ペース・用途別の内訳）／ 予算 ／ 推移（直近12ヶ月・年ごと） |
| **履歴** | 一覧（検索・絞り込み）／ カレンダー |
| **予定** | 引落口座ごとのまとめ ／ カード別の支払予定 |
| **設定** | 支払方法（＋祝日）／ 定期 ／ 用途 ／ その他（節約診断・バックアップ・テーマ・更新履歴） |
| **＋** | 記録（金額・用途・支払方法・よく使う入力・支出/立替/収入） |

## できること

- **記録** — 金額は端末標準の数字キーボード、用途と支払方法はプルダウンで選ぶ。
  プルダウンの末尾の「＋ 新しく追加…」でその場で増やせる。
  よく使う「用途 ・ 支払方法」の組み合わせはワンタップで選べる（金額とメモは触らない）。
  PCでは Enter で保存できる
- **定期** — 毎週/毎月/毎年に加えて「2週間ごと」「3ヶ月ごと」のような間隔も指定できる。
  一時停止・解約予定も期間どおりに効く
- **支払予定** — クレジットカードの締め日・支払日・休日調整から、次回いくら引き落とされるかを計算
- **書き出し** — JSON（バックアップ用）と CSV（Excel用）、AIに相談するためのテキスト
- **更新のお知らせ** — 新しい版が届くと、何が変わったのかを並べて知らせる。
  過去のぶんは 設定 → その他 → 更新履歴 から読める

## 画面の外枠

ページ全体ではなく、**`<main>` の中だけがスクロールする**（ヘッダーと下タブは
フレックスの外側の行として固定）。ページ自体をスクロールさせると、スマホの
ブラウザが上のURLバーを隠そうとして画面の高さを変え、そのあいだ下タブが
本文と一緒に動いてしまうため。この形なら下タブは1pxも動かず、
下に引っ張ったときの再読み込みの誤爆も起きない。

そのぶん、`main` には `tabindex="-1"` を付けて画面切り替えのたびに
フォーカスを移している。PCの PageDown・スペースでスクロールできるように、
かつ読み上げに画面が変わったことを伝えるため。

## 端末ごとの見た目

PC・iPhone・Android のどれでも使える。Android で開いたときだけ、
書体（Roboto / Noto Sans JP）・角丸・押したときの波紋・FABの形を
Material 寄りに変え、**「戻る」で入力シートが閉じる**ようにしている
（`index.html` の `§A android` と `const Android`）。
iPhone と PC の見た目は変えていない。

## データの扱い

家計データは**閲覧している端末のブラウザの localStorage にのみ**保存される。
サーバーには送信されず、このリポジトリにも含まれない。

そのため、端末を変えるときやブラウザのデータを消すときは、
設定 → その他 → バックアップ から JSON を書き出しておくこと。
設定画面に最後に書き出した日が出るので、30日を過ぎると注意書きが出る。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体。これ1枚で動く |
| `sw.js` | オフライン用。**更新したら中の `CACHE` の文字列を必ず変える** |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコン |
| `icon.svg` / `icon-192.png` / `icon-512.png` / `apple-touch-icon.png` | アイコン |
| `v1.html` | 旧バージョン。移行に問題が出たとき用。しばらく残す |
| `v2.html` | 旧プレビューURL。`index.html` へ転送するだけ |

## 直すとき

`index.html` を直したら、**`sw.js` の `RELEASES` のいちばん上に新しい項目を足す**こと。

```js
const RELEASES = [
  { version:"2026-10-15a", date:"2026-10-15", notes:[
    "何が変わったのかを、使う人の言葉で書く",
  ]},
  …
];
```

- `notes` に書いた文章は、そのままアプリの「更新のお知らせ」に出る
- キャッシュ名はこの `version` から作るので、別に直す必要はない
- ブラウザは **`sw.js` の中身が変わったときだけ**更新に気づく。
  ここに足すこと自体がお知らせの引き金なので、書き忘れると
  利用者の端末はいつまでも古いままになる

過去の `notes` は、アプリの 設定 → その他 → 更新履歴 から読める。

### 自己テスト

URL に `?selftest=1` を付けると、日付計算・カードの締め日・予算の繰り越し・
集計・データ移行などの自己テストが走る。

**https://tmgr490.github.io/kakeibo/?selftest=1**

localStorage には一切触らないので、実データがあるまま実行しても安全。

## ご意見箱

設定 → その他 の「ご意見・ご要望」から、作っている人にだけ意見が届く。
宛先は [Web3Forms](https://web3forms.com/)（無料枠 月250件・サインアップ不要）。

`index.html` の先頭近くの1行だけが宛先の設定。

```js
const FEEDBACK_KEY = "";   // web3forms で発行されるアクセスキーを貼る
```

- **空のあいだは意見箱そのものが画面に出ない。** 貼って初めて有効になる
- このキーは公開前提の仕組みで、キーからメールアドレスは割れない。
  だから public リポジトリに置いても「個人情報を載せない」方針と矛盾しない
- **迷惑メールが来るようになったら**、web3forms でキーを作り直して
  この1行を貼り替えるだけでよい（古いキーは使えなくなる）
- 送るのは **種別・本文・連絡先（任意）・アプリの版・端末の種類と画面幅** だけ。
  家計のデータは1バイトも送らない。送る中身を決めているのは
  `Feedback.payload()` の1箇所だけで、自己テスト（S19）がそれを見張っている
- 1つの端末から1時間に5件まで。無料枠を使い切らないための保険

## 既知の制限

- **同じ端末で複数のタブを同時に開かない。** データはタブごとにメモリ上にも
  持っているので、両方で編集すると、後から保存した側の内容で上書きされる。
- データは閲覧している端末のブラウザにしか無い。端末を変えるときは
  先にバックアップを書き出すこと。

## このリポジトリに入れないもの

public リポジトリなので、コードには以下を含めない。

- 実在するクレジットカード名・銀行名・引落口座名
- 契約中のサブスクのサービス名や金額
- 実際の取引履歴・残高・金額

サンプルやテストデータが必要な場合は、`カードA` `口座A` `定期購読A` のような
合成値を使う。入力欄のプレースホルダにも固有名詞を書かない。
