# kakeibo

個人用の家計簿アプリ。ビルド不要の単一HTMLで、GitHub Pages から配信している。

**https://tmgr490.github.io/kakeibo/**

ホーム画面に追加すると、アプリのように起動してオフラインでも使える。

## 画面の構成

| 画面 | 中身 |
|---|---|
| **ホーム** | 今月（収支・次の引き落とし・ペース・用途別の内訳）／ 予算 ／ 推移（直近12ヶ月・年ごと） |
| **履歴** | 一覧（検索・絞り込み）／ カレンダー |
| **予定** | 引落口座ごとのまとめ ／ カード別の支払予定 |
| **設定** | 支払方法（＋祝日）／ 定期・積立 ／ 用途 ／ その他（節約診断・バックアップ・テーマ） |
| **＋** | 記録（テンキー・よく使う入力・支出/立替/収入/貯蓄） |

## できること

- **記録** — 電卓風のテンキーで入力。よく使う組み合わせはワンタップ。PCではキーボードでも打てる
- **貯蓄・投資** — 積立NISAなどは支出ではなく「振替」として別に集計し、貯蓄率も出す
- **定期・積立** — 毎週/毎月/毎年に加えて「2週間ごと」「3ヶ月ごと」のような間隔も指定できる。
  一時停止・解約予定も期間どおりに効く
- **支払予定** — クレジットカードの締め日・支払日・休日調整から、次回いくら引き落とされるかを計算
- **書き出し** — JSON（バックアップ用）と CSV（Excel用）、AIに相談するためのテキスト

## データの扱い

家計データは**閲覧している端末のブラウザの localStorage にのみ**保存される。
サーバーには送信されず、このリポジトリにも含まれない。

そのため、端末を変えるときやブラウザのデータを消すときは、
設定 → その他 → バックアップ から JSON を書き出しておくこと。
設定画面に最後に書き出した日が出るので、30日を過ぎると注意書きが出る。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体。これ1枚で動く |
| `sw.js` | オフライン用。**更新したら中の `CACHE` の文字列を必ず変える** |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコン |
| `icon.svg` / `icon-192.png` / `icon-512.png` / `apple-touch-icon.png` | アイコン |
| `v1.html` | 旧バージョン。移行に問題が出たとき用。しばらく残す |
| `v2.html` | 旧プレビューURL。`index.html` へ転送するだけ |

## 直すとき

`index.html` を直したら、**`sw.js` の `CACHE` の文字列も一緒に変える**こと。
変え忘れると、オフライン用に取ってある古い版が出続ける。

### 自己テスト

URL に `?selftest=1` を付けると、日付計算・カードの締め日・予算の繰り越し・
集計・データ移行などの自己テストが走る。

**https://tmgr490.github.io/kakeibo/?selftest=1**

localStorage には一切触らないので、実データがあるまま実行しても安全。

## このリポジトリに入れないもの

public リポジトリなので、コードには以下を含めない。

- 実在するクレジットカード名・銀行名・引落口座名
- 契約中のサブスクのサービス名や金額
- 実際の取引履歴・残高・金額

サンプルやテストデータが必要な場合は、`カードA` `口座A` `定期購読A` のような
合成値を使う。入力欄のプレースホルダにも固有名詞を書かない。
